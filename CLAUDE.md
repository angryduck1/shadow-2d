# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

«Тень Старшего Брата» — 2D-стратегия на Bevy 0.16 (Rust 2021) по альтернативной истории лунной гонки 1973–1978. Код, комментарии, тексты и коммуникация — на русском. Сюжет и лор: `docs/Трилогия «Тень Старшего Брата».md`; новые тексты и события брать оттуда.

## Команды

```
cargo run --release                     # игра (первая сборка движка — 10–20 минут)
cargo test                              # все тесты (~3 с, профиль test собран с opt-level 2)
cargo test every_ending -- --nocapture  # 120 000 партий + кратчайший найденный путь к каждой развязке
SHADOW_SEED=2 SHADOW_AUTOPLAY="s 1 1 2" cargo run --release   # автопрохождение
```

`SHADOW_AUTOPLAY`: `s` — пробел/пропуск анимации, `1`/`2` — выбор (ждёт конца анимаций), `w` — пауза, `e` — открыть/закрыть галерею развязок, `v` — следующая развязка в ней; шаг задаёт `SHADOW_AUTOPLAY_STEP` (секунды). `SHADOW_SHOTS=<папка>` сохраняет снимок окна каждые `SHADOW_SHOTS_STEP` секунд — так сцены проверяются без игрока (под Wayland внешние утилиты снимков окно не видят). `SHADOW_PARADE=<секунды>` показывает по очереди все кризисы, события и развязки (`GameState::showcase`); вместе с `SHADOW_SHOTS` даёт снимок каждой сцены. Галерея читает `endings.txt` из `$XDG_DATA_HOME/shadow-2d/` — для проверки подставляйте временный `XDG_DATA_HOME`. `SHADOW_SEED` фиксирует случайные события, так можно повторить маршрут из вывода теста. Clippy в окружении не установлен.

Игру запускать из корня проекта: `assets/` ищется в папке запуска (`asset_root()` в `main.rs`), иначе рядом с бинарником. На Linux для сборки нужна ALSA (`alsa-lib-devel`).

## Архитектура

- `src/game.rs` — все правила; **не зависит от Bevy**. Доктрина «победа любой ценой»: бунт (`Uprising`), пустая касса (`Bankrupt`), война (`MoonWar`) и ядерный порог (`Brink`) — кризисы с выбором, а не концы партии. `GameState` (`Copy`, без кучи; миссии — битовая маска `Missions`) — граф сцен: `Location` (локации, кризисы, 19 развязок в `Location::ENDINGS`, исход — `outcome()`), `apply(choice) -> Turn` возвращает сводку и очередь `Cutscene`. Переходы после хода идут через `proceed()` (приоритет: кризис власти → высадка СССР → ООН → событие досье → стартовый стол → резервный рейс → победа в войне → Политбюро → финальный кризис). Случайность — LCG в поле `rng` самого состояния, поэтому партия детерминирована.
- Тест `every_ending_is_reachable` разыгрывает 120 000 детерминированных партий (40 зёрен, разная склонность к первому варианту) и проверяет: каждая развязка и каждое `Event` достижимы, все 11 видов `Cutscene` встречаются, ни один ключ текста не отсутствует. Полный перебор графа невозможен (сотни миллионов состояний). При новой развязке/событии/анимации тест должен остаться зелёным; у развязки нужны ключи `title`, `text`, `epi`, `hint`. Ключи в `dialogs.txt` должны быть уникальны (тест это проверяет).
- `assets/dialogs.txt` — все тексты (`@ключ` начинает запись, `@--` — комментарий). Вшит в бинарник, файл на диске перекрывает по ключам (`src/content.rs`). Ключи собираются из `Location::key()`, `Mission::key()`, `Event::key()`: `title.<loc>`, `text.<loc>`, `opt1.<loc>`, `res1.<loc>`, `<mission>.report`, `lore.<name>.name/text`, `chapter.<n>.*`, `cut.*`, `ui.*`. Отсутствующий ключ даёт `[нет текста]`, и тест это ловит.
- `src/paint.rs` — `Painter` рисует сцену только примитивами (rect/tri/ellipse/text/paragraph, картинок нет) и компоненты анимации, которые работают от `SceneClock` (секунды с начала сцены): `Motion`, `Slide` (точная длительность с замедлением), `Orbit`, `Reveal`, `Fade` (ключевые кадры прозрачности), `Flicker`, `Grow`, `Twinkle`, `Blink`, ресурс `CameraShake`. Небесные орбиты (`orbit_body` + `Body`) идут по `OrbitClock` (клавиши `[`/`]`), подчиняются Кеплеру и уходят за диск планеты; `hotspot` даёт подсказку под курсором (`Inspect`). Всё нарисованное помечается `SceneEntity` и стирается при `Canvas::begin`.
- `src/gallery.rs` — экран `Screen::Gallery` (клавиша E), открытые развязки сохраняются в `endings.txt` в папке данных пользователя.
- `src/scenes.rs` — `draw_location` (статичная сцена места + проявление из черноты) и `draw_cutscene` (возвращает длительность). Соглашения: пунктир траектории (`dashes`), рамка цели (`target_mark`), подтверждающая надпись (`flash_label`), затемнение (`curtain`), кинорамка (`letterbox`). Видимая область сцены 920×490, центр — начало координат.
- `src/main.rs` — экраны `Screen::{Title, Playing, Cutscene, Gallery}`, ресурс `Session` (состояние, сводка, очередь анимаций, досье), ввод, автопрохождение. `src/hud.rs` — правая панель и нижний диалог (Bevy UI), обновляется по изменению `Session`.
- `src/audio.rs` — три зацикленных трека (`assets/audio/episode1.ogg`, `episode2.ogg`, `lore.ogg`, пути относительно `assets/`), у каждого свой плеер на всю игру; `choose_track` выбирает трек по экрану/локации, `crossfade` плавно меняет громкость и ставит неактивные на паузу. Отсутствующий файл просто пропускается.
