# Музыка: ISOTOPE WARS — ARC 1 OST

Положите сюда три файла в формате Ogg Vorbis. Игра зацикливает каждый трек
и плавно переключает их при смене сцены. Если файла нет, игра идёт без него.

| Файл | Отрезок видео | Где звучит |
|---|---|---|
| `episode1.ogg` | 0:00–3:38, музыка Эпизода 1 | заставка, книга первая, подготовка проекта |
| `episode2.ogg` | 3:38–9:35, музыка Эпизода 2 | анимации запусков, кризисы, развязки |
| `lore.ogg` | 9:35–16:45, музыка Lore Videos | стартовая площадка, Луна, ООН, события, досье |

Нарезать треки из файла видео можно так (нужен ffmpeg):

```
ffmpeg -i ost.webm -ss 0:00 -to 3:38  -vn -c:a libvorbis -q:a 5 episode1.ogg
ffmpeg -i ost.webm -ss 3:38 -to 9:35  -vn -c:a libvorbis -q:a 5 episode2.ogg
ffmpeg -i ost.webm -ss 9:35 -to 16:45 -vn -c:a libvorbis -q:a 5 lore.ogg
```

Логика выбора трека — `src/audio.rs`, функция `choose_track`.
